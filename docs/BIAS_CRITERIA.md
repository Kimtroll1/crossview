# CrossView 편향 신호 기준

## 정치 방향

```text
-5 진보 ←──────── 0 중립 ────────→ +5 보수
```

정당 이름만으로 결정하지 않고 정책·인물·집단에 대한 긍정/부정 프레임, 가치 판단, 반론 처리 방식을 종합합니다. 비정치 영상은 0으로 처리합니다.

## 편향 신호 4종

각 신호는 `0~5`이며 높을수록 해당 방식이 강하게 관찰됐다는 의미입니다.

### 감정·선동

공포, 분노, 혐오, 조롱, 위기감, 집단 적대 표현으로 판단을 유도하는 정도.

### 선택적 근거

주장에 유리한 통계·사례·발언만 제시하고 불리한 근거나 한계를 생략하는 정도.

### 관점 누락

반론, 다른 이해관계자, 예외 사례, 불확실성을 충분히 소개하지 않는 정도.

### 출처 편중

한 기관, 한 인물, 한 언론, 익명 출처에 과도하게 의존하는 정도.

## 댓글 흐름

댓글은 전체 사회 여론을 대표하지 않으므로 동의·중립·반대 비율을 사용하지 않습니다.

- 의견 쏠림: 다양한 의견이 공존하는지 한쪽에 집중되는지
- 감정 강도: 차분한 토론인지 공격·조롱·분노가 강한지
- 짧은 서술형 요약과 표본 수를 함께 표시

## 신뢰도와 판단 근거

정치 방향에는 `biasConfidence`를 함께 표시하고, 모든 편향 신호에는 관찰 근거를 최대 2~3개 제시합니다. 데이터가 부족하면 점수를 낮추거나 정보 부족을 명시합니다.
